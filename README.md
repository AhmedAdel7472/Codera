# EduVerse AI Placement Assessment Framework

An adaptive, game-based, AI-driven digital placement assessment system engineered with a standardized scoring model across 5 core competency domains:

- **Cognitive Ability** (25% Weight, 25 Max Score)
- **Functional Skills** (25% Weight, 25 Max Score)
- **Communication Level** (20% Weight, 20 Max Score)
- **Behavioral Learning Readiness** (15% Weight, 15 Max Score)
- **Fine Motor & Technology Skills** (15% Weight, 15 Max Score)

## Features
- **Standardized Scoring & Telemetry Engine**: Computes accuracy, response latency, hint dependency, and error recovery metrics scaled to a 100-point total.
- **Azure OpenAI (o4-mini) Integration**: Dynamic AI item generation and qualitative student diagnostic summaries.
- **Interactive 20-Question Matrix Web Runner**: Sleek dark glassmorphism UI with live pre-fetching, dynamic options grids, robot coding block missions, audio matching prompts, rule shift sorting, and target precision controls.
- **Diagnostic Placement Dashboard**: Recommends student learning track (`Explorer`, `Builder`, `Creator`, `Innovator`, `Future Engineer`) and flags domain deficiencies.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Local Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
