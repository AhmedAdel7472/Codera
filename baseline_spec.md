# ASSESSMENT PURPOSE

The purpose of this assessment is to identify the student's current level of readiness for technology-based learning, including coding, robotics, digital learning, problem solving and technology-supported educational activities.

The assessment evaluates five domains:

1. Cognitive Abilities
2. Functional Abilities
3. Communication Level
4. Behavioral & Learning Readiness
5. Fine Motor & Technology Skills

The total score is **100 marks**.

# PERFORMANCE LEVEL

### LEVEL 1 — EXPLORER

**0–59**

Student requires significant support and benefits from highly structured, visual and hands-on learning.

Recommended focus:

* Basic digital awareness
* Cause & effect
* Matching and sequencing
* Simple robotics manipulation
* Visual instructions
* Fine motor development
* Basic technology interaction

---

### LEVEL 2 — BUILDER

**60–74**

Student demonstrates emerging readiness for structured technology and coding activities.

Recommended focus:

* Block-based coding introduction
* Basic robotics
* Sequencing
* Following multi-step instructions
* Digital navigation
* Guided problem solving

---

### LEVEL 3 — CREATOR

**75–89**

Student demonstrates good readiness for structured coding, robotics and technology learning.

Recommended focus:

* Scratch/block coding
* Robotics projects
* Logic and problem solving
* Independent digital tasks
* Project-based learning

---

### LEVEL 4 — INNOVATOR

**90–100**

Student demonstrates strong readiness for advanced technology-based learning.

Recommended focus:

* Advanced coding
* Robotics programming
* Engineering challenges
* Computational thinking
* Project-based technology learning
* Advanced problem solving
