# CodeRa Onboarding Prototype

This is the fully polished onboarding flow for CodeRa, perfectly matching the design specs and using the requested assets.

## To use your images:
Drop your images in the `public/` directory with the following structure:
- `public/logo.png`
- `public/assets/builder-role.png`
- `public/assets/mentor-role.png`
- `public/assets/coider.png`
- `public/assets/code-guide.png`
- `public/assets/programmer.png`
- `public/assets/special-ed.png`
- `public/assets/school.png`
- `public/assets/center.png`

Vite will serve them automatically!
